# Athlete Premium

## Contexte

Athlete Premium est une application premium de suivi sportif inspirée par Whoop, Hevy et Apple Fitness.

Ce projet est destiné à devenir une vraie application web puis mobile.

Le design actuel est considéré comme validé. Il ne doit pas être modifié sans autorisation.

## Mon rôle

Je suis le Product Owner.

Je ne suis pas développeur.

Je compte sur GitHub Copilot pour m'aider à développer l'application.

## Ton rôle

Tu es un développeur senior Front-End.

Avant toute modification importante :

- analyse le projet ;
- explique ce que tu veux faire ;
- attends ma validation.

Ne fais jamais de gros changements d'architecture sans les expliquer.

## Contraintes

- Ne pas modifier le design.
- Ne pas modifier les couleurs.
- Ne pas modifier les polices.
- Ne pas modifier les animations existantes.
- Conserver le style premium.
