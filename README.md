# Athlete Premium

Athlete Premium est une application premium de suivi sportif inspirée de Whoop, Hevy et Apple Fitness.

## 🎯 Objectif
Transformer progressivement une maquette HTML en une application complète :
- Données dynamiques
- Profil utilisateur
- Historique
- Graphiques
- React
- Supabase
- Publication finale
